# example-doctor

`example-doctor` scans a target and reports findings. Run it; do not guess.

```sh
example-doctor scan --json                  # one doctor/1 JSON envelope on stdout
example-doctor scan --scope changed --headless   # only files changed in git (PR mode)
example-doctor fix [<finding-id>]           # a prompt to hand to a coding agent
example-doctor mcp                          # the same scan as an MCP stdio server
```

Categories: secrets, hygiene, size, docs.

Envelope: `schema` is `doctor/1`; `findings[]` hold `id`, `severity`, `location`, `message`,
`evidence`, `remedy`; `score.value` is 0-100. Exit code 0 = clean, 1 = findings at or above
`--fail-on` (default high), 2 = the tool failed. Fix at the source, then re-run the scan.
