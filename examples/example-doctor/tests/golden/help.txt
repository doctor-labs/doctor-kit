$ example-doctor scan --help
exit: 0
--- stdout ---
Scan a target and print a report

Usage: example-doctor scan [OPTIONS] [PATH]

Arguments:
  [PATH]
          Directory to examine
          
          [default: .]

Options:
      --scope <SCOPE>
          full, or only changed files (worktree vs HEAD, untracked, and `--base`)

          Possible values:
          - full
          - changed: Files in `git diff HEAD`. Falls back to full when git is unavailable
          
          [default: full]

      --base <BASE>
          PR mode: with `--scope changed`, also files changed since merge-base(BASE, HEAD)

      --config <CONFIG>
          doctor.toml (default: <path>/doctor.toml when present)

      --fail-on <FAIL_ON>
          Exit 1 when a finding is at or above this severity
          
          [default: high]

      --face <FACE>
          Output face

          Possible values:
          - plain:   Minimalist text, one line per finding
          - rich:    Boxed report with a score gauge, grouped by category
          - compact: One-line summary plus a findings table
          
          [default: rich]

      --theme <THEME>
          mono | clinical | contrast (default: the doctor's own theme)

      --theme-file <THEME_FILE>
          theme.toml overlay (default: <path>/theme.toml when present)

      --color <COLOR>
          [default: auto]
          [possible values: auto, always, never]

      --json
          Print the doctor/1 envelope as JSON

      --score
          Print only the score number

      --headless
          Plain text, no color: for CI and pipes

      --sarif <SARIF>
          Also write a SARIF 2.1.0 report to this path

      --baseline <BASELINE>
          Compare with a saved doctor/1 report: findings get baseline_state, exit 3 only for NEW ones

  -h, --help
          Print help (see a summary with '-h')
--- stderr ---

$ example-doctor fix --help
exit: 0
--- stdout ---
Print (or copy) a prompt for a coding agent from one finding or the whole scan

Usage: example-doctor fix [OPTIONS] [ID]

Arguments:
  [ID]
          Finding rule id or fingerprint prefix (default: every finding)

Options:
  -C, --path <PATH>
          Directory to scan
          
          [default: .]

      --scope <SCOPE>
          full, or only changed files (worktree vs HEAD, untracked, and `--base`)

          Possible values:
          - full
          - changed: Files in `git diff HEAD`. Falls back to full when git is unavailable
          
          [default: full]

      --base <BASE>
          PR mode: with `--scope changed`, also files changed since merge-base(BASE, HEAD)

      --config <CONFIG>
          doctor.toml (default: <path>/doctor.toml when present)

      --fail-on <FAIL_ON>
          Exit 1 when a finding is at or above this severity
          
          [default: high]

      --copy
          Also copy the prompt to the clipboard

      --from <FROM>
          Take the findings from this saved `scan --json` report instead of scanning

      --agent <AGENT>
          Hand the prompt to this coding agent instead of printing it
          
          [possible values: claude, codex, cursor]

      --yolo
          With --agent: skip the agent's approval prompts (the scanned text is untrusted)

  -h, --help
          Print help (see a summary with '-h')
--- stderr ---

Write an agent skill, Cursor rule and AGENTS.md block into a repo

Usage: example-doctor install [OPTIONS]

Options:
      --dir <DIR>
          Repository to write into
          
          [default: .]

      --agent <AGENT>
          One agent only (default: all)

          Possible values:
          - claude
          - cursor
          - codex:    Codex and opencode both read AGENTS.md
          - opencode

      --agent-hooks
          Also add a Claude Code PostToolUse hook that scans changed files after edits

      --print-only
          Print the files instead of writing them

  -h, --help
          Print help (see a summary with '-h')
